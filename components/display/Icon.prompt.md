Renders a glyph from Jin Icons, the kit's Lucide-derived 1520-icon set.

```jsx
<Icon name="search" size={24} />
<Icon name="heart" size={20} color="var(--color-icon-accent)" />
```

Sizes 12/16/20/24/32/40/48. Default colour is the kit's icon grey #95A0B2; stroke is 1.5.
Glyphs are fetched from the lucide-static CDN, so an offline page shows an empty box.
